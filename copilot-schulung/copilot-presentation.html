KI-Assistent, nicht Autopilot

Sie behalten immer das Steuer. Die KI ist Ihr Co-Pilot, nicht der Kapitän.

Der Pilot

Sie behalten das Steuer

Entscheidungsträger
Sie prüfen, bewerten und tragen die finale Verantwortung für jedes Ergebnis.
Kontext-Lieferant
Sie bringen geschäftliches Know-how und Urteilsvermögen ein, das keine KI ersetzen kann.
Qualitätsprüfer
Sie definieren, was brauchbar ist, und geben der KI Folgeanweisungen zur Verbesserung.
Verantwortung bleibt stets beim Menschen
Der Co-Pilot

Die KI unterstützt Sie

Sekundenschnell
Generiert Entwürfe, Zusammenfassungen und Analysen in Sekunden statt Stunden.
Routineaufgaben
Copilot übernimmt Protokolle, Formatierungen und erste Entwürfe. Sie verfeinern nur noch.
Breites Hintergrundwissen
Nutzt Web, Microsoft Graph und Ihre M365-Daten als umfassende Wissensgrundlage.
Schlägt vor, Sie entscheiden
Sie bleiben immer am Steuer. Die KI schlägt vor, Sie entscheiden, was genutzt, bearbeitet oder ignoriert wird.

Ein Blick in die Zukunft: Copilot Agents

Was ist der Unterschied zwischen einem einfachen Prompt und einem autonomen Agenten?

Standard Copilot
Auf Anfrage · Reaktiv
Das Prinzip
Sie stellen eine Frage und Copilot antwortet. Leistungsstark, aber immer reaktiv und wartet auf Ihren Input.
Auslöser
Immer Ihr Prompt. Ohne Frage keine Aktion.
Ablauf
Ein Schritt: Frage → Antwort
Beispiel
"Fasse diesen Vertrag zusammen." → Copilot liefert die Zusammenfassung.
Copilot Agents
Autonom · Proaktiv
Das Prinzip
Einmal eingerichtet, läuft der Agent selbstständig: mehrstufig, proaktiv, auch wenn Sie offline sind.
Auslöser
Ein Ereignis oder Zeitplan, kein manueller Prompt nötig
Ablauf
Mehrere Schritte: prüfen → entscheiden → handeln → benachrichtigen
Beispiel
Neuer Vertrag eingetroffen → Agent prüft Klauseln → erstellt Bericht → sendet ihn ans Legal-Team.

Flugregeln: Stärken nutzen, Grenzen kennen

Copilot ist ein mächtiges Werkzeug, wenn Sie wissen, wo es glänzt und wo Sie kritisch bleiben müssen.

Was Copilot kann
Leeres-Blatt-Syndrom überwinden
Erste Entwürfe entstehen in Sekunden. Sie konzentrieren sich nur noch auf das Verfeinern.
Enorme Geschwindigkeit
Routineaufgaben wie Zusammenfassungen, E-Mails und Protokolle werden massiv beschleunigt.
Kein Workflow-Unterbruch
Direkt in Word, Teams und Outlook integriert. Kein Kontextwechsel, kein neues Tool lernen.
Was Sie wissen müssen
Halluzinationen möglich
Copilot kann plausible, aber falsche Fakten erfinden. Wichtige Daten immer verifizieren.
Kein Fachexperte
Copilot hat kein menschliches Urteilsvermögen und keine emotionale Intelligenz. Das bleibt Ihre Aufgabe.
Kontext-abhängig
Ohne präzise Anweisungen entstehen nur generische Ergebnisse. Guter Prompt ergibt gutes Ergebnis.

Prompts formulieren: Wie Sie richtig delegieren

Vier Zutaten für einen perfekten Prompt. So einfach ist das Rezept.

01
Ziel
+
02
Kontext
+
03
Format
+
04
Tonfall
=
Ergebnis
Perfekter Prompt
Ziel
Was soll passieren?
Beschreiben Sie die Aufgabe konkret. Nicht "schreib etwas", sondern "erstelle", "fasse zusammen", "überarbeite".
"Erstelle eine Executive Summary …"
Kontext
Wofür und für wen?
Je mehr Hintergrund, desto besser das Ergebnis. Zielgruppe, Projekt, Situation: Alles zählt.
"… der Q1-Verkaufsergebnisse für den Vorstand …"
Format
Wie soll es aussehen?
Länge, Struktur, Ausgabeform bestimmen. Tabelle, Stichpunkte, E-Mail oder 3 Sätze: Sie entscheiden.
"… als 5 Stichpunkte, max. eine A4-Seite …"
Tonfall
Wie klingt es?
Formell, locker, direkt, empathisch? Copilot passt sich an. Sagen Sie ihm, was Sie brauchen.
"… in einem sachlichen, professionellen Tonfall."
Alles zusammen ergibt einen starken Prompt:
"Erstelle eine Executive Summary der Q1-Verkaufsergebnisse für den Vorstand, als 5 Stichpunkte auf einer Seite, in einem sachlichen, professionellen Tonfall."

3

Sicher fliegen: Datenschutz im Fokus

Microsoft 365 Copilot ist kein öffentliches KI-Tool. Diese Garantien gelten für Ihr Unternehmen.

Ihre Daten verlassen niemals Ihre Microsoft 365-Umgebung.
Copilot arbeitet ausschliesslich innerhalb Ihres Unternehmens-Tenants, mit denselben Sicherheits- und Compliance-Standards wie alle anderen Microsoft 365-Dienste.
Zertifiziert
ISO 27001
SOC 2 · GDPR
Im Tenant verschlossen
Copilot greift auf Ihre Unternehmensdaten zu, doch diese verlassen niemals die sichere Microsoft 365-Umgebung Ihres Unternehmens.
✓ Garantiert
Kein Datentransfer ausserhalb Ihres Tenants
Kein KI-Training
Ihre Prompts, Antworten und Dokumente werden nicht verwendet, um öffentliche KI-Modelle zu trainieren, weder von Microsoft noch von Dritten.
✓ Garantiert
Ihre Daten trainieren keine öffentlichen Modelle
Strikte Berechtigungen
Copilot sieht nur, was Sie selbst sehen dürfen. Alle bestehenden SharePoint-Freigaben und Zugriffsrechte gelten unverändert.
✓ Garantiert
Keine Umgehung bestehender Zugriffsrechte

Bereit zum Abflug: Ihre Checkliste

Fünf Regeln für Ihren KI-Alltag. Alle abhaken und durchstarten.

Abflugcheck
alle 5 abhaken ✈
Sie sind der Pilot
Copilot schlägt vor, Sie entscheiden. Die finale Verantwortung liegt immer bei Ihnen.
Präzise prompten
Nutzen Sie die Formel: Ziel + Kontext + Format + Tonfall für messbar bessere Ergebnisse.
Ausgaben kritisch prüfen
Fakten und Zahlen immer gegenprüfen. Copilot kann sich irren. Sie sind das letzte Korrektiv.
